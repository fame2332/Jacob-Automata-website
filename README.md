# Automata Project

A modern web application showcasing automata theory concepts with an interactive and engaging user interface. Built with React, TypeScript, and Tailwind CSS.

## 🌟 Features

- **Interactive Automata Visualization**
  - Dynamic state machine representation
  - Real-time state transitions
  - Visual feedback for user interactions

- **Modern UI/UX**
  - Clean, responsive design
  - Smooth animations and transitions
  - Interactive background effects
  - Engaging loading animations

- **Multiple Sections**
  - Home: Main dashboard and overview
  - About: Project information and background
  - Members: Team member profiles
  - Contact: Contact form and information

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm (v6.0.0 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/fame2332/Jacob-Automata-website
   cd automata-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```
